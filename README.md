# 🖼️ PIXEL RESURRECT — AI Image Restoration Studio

**PIXEL RESURRECT** is an AI-powered image restoration studio designed to help users improve old, damaged, faded, or low-quality photographs through a modern web interface.

Bring your memories back to life with image enhancement, restoration workflows, and before-and-after comparison.

---

# ✨ Features

## 🪄 Image Restoration Studio
Upload an image and use the available restoration tools to improve its visual quality.

## 🔍 Before & After Comparison
Compare the original and processed images to review restoration results.

## 🖼️ Image Upload & Preview
Select an image from your device and preview it in the studio.

## 🎨 Modern User Interface
A polished, responsive interface built for a focused image-editing experience.

## ⚡ Browser-Based Workflow
Use the application through a web browser without installing a desktop image editor.

> Note: Actual AI restoration capabilities depend on the configured processing service and API credentials. Do not describe a feature as AI-powered unless its processing integration is configured and working.

# 🚀 Run Locally

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal (commonly `http://localhost:3000` or the port shown by the development server).

To stop the server, press `Ctrl + C`.

## 🪟 Windows Quick Start

If `run.bat` is included in the project root:

1. Open the project folder.
2. Double-click `run.bat`.
3. Wait for the development server to start.
4. Open the local URL shown in the terminal.

# 🛡️ Image & Privacy Notes

- Use images that you own or have permission to process.
- Avoid uploading sensitive photographs to third-party services unless you understand their privacy terms.
- Keep API keys and secrets out of source control.
- Store credentials in environment variables when required.
- Test restoration results before replacing or deleting original images.
- Keep an untouched copy of important photographs.
